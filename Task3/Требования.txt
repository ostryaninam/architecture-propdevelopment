1. Требования к безопасности внешних интеграций

1) Шифрование данных

Все взаимодействия должны происходить исключительно по защищённым каналам — HTTPS/TLS 1.2+.
Передача биометрических данных и номеров авто — обязательно в зашифрованном виде.
Хранение данных в smart-home-db — только в зашифрованном виде (атрибуты биометрии, логи доступа).

2) Журналирование

Все обращения к API партнёра должны логироваться.
Необходимо сохранять: дату, идентификатор пользователя, действие, результат.

3) Ограничение доступа

Только smart-home-integration-service имеет доступ к API.
Сервис работает от специальной технической учётной записи, не от имени пользователя.

4) Проверка соответствия законодательству

Хранение и передача биометрических данных должны соответствовать:
152-ФЗ (о персональных данных),
210-ФЗ (в части идентификации граждан),
Постановлению Правительства РФ №1119 (меры по ИБ).

2. Протоколы аутентификации и авторизации

1) Аутентификация

Используется токен-авторизация по OAuth2.0 Client Credentials:
Платформа "Умный дом" выдаёт клиентский client_id и client_secret для PropDevelopment.
smart-home-integration-service получает access token через /token.
Все запросы к API содержат Authorization: Bearer <token>.

2) Авторизация

Все действия API проверяются на допустимость команд от клиента PropDevelopment.
Партнёрская система не должна допускать вызов функций или изменение данных вне разрешённых сценариев.

3. Взаимодействие между системами PropDevelopment и внешней платформой

1) Схема обмена

1.1 от smart-home-integration-service к API умного дома	
Команды: открыть/отклонить
1.2 от API умного дома к smart-home-integration-service
Статусы: шлагбаум открыт, ошибка распознавания авто
1.3 от smart-home-integration-service к API умного дома	
Биометрические шаблоны, номера авто

2) Канал связи
REST API для вызовов команд и синхронных запросов.
WebSocket (опционально) для push-уведомлений (в будущем).
Протоколы: HTTPS, формат данных: JSON.

3) Согласование контрактов
Используются формализованные OpenAPI спецификации.
Все поля, касающиеся персональных данных, должны быть помечены, документированы и согласованы с ИБ.
